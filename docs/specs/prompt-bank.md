# Elza Prompt Bank · 产品功能规格

> 所属分类：Elza / prompt  
> 状态：0.2.0-alpha.8 待人工 UI 验收  
> 最后更新：2026-09-03

## 1. 功能定位

从结构化词库中查找并选择多个词条，调整顺序，输出稳定 Prompt。已选区支持逐条设置词条权重；蓝图节点上的最终权重仍用于包装完整 Bank 输出。

```text
节点本体                         Prompt Bank 弹窗
┌────────────────────┐          ┌─────────────────────────────────────┐
│ 打开 Prompt Bank   │   打开   │ 文件/搜索/状态                      │
│ 已选摘要（只读）    │ ───────→ │ 分类树 │ 词条列表 │ 已选内容与预览   │
│ extra_prompt       │          │ 一级在左 / 二级顶部 / 词条主体      │
│ 最终权重 [1.00]    │          │                                     │
└────────────────────┘          └─────────────────────────────────────┘
```

## 2. 节点本体

| 控件 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 打开 Prompt Bank | 按钮 | — | 打开选择模式弹窗 |
| 已选摘要 | 只读多行文本 | `(空)` | 展示当前已选词条，不作为复杂状态主存储 |
| extra_prompt | 多行 STRING | 空 | 追加自由文本，支持公共随机语法 |
| 最终权重 | FLOAT | 1.0 | 1 时不加括号；其他值包装完整输出 |
| text | STRING 输出 | — | 已选词条（逐条权重）与 extra_prompt 拼接后应用最终权重 |

## 3. 弹窗布局与维护

- 左侧只显示一级 Tag。
- 中间顶部显示二级 Tag 单行导航；多时横向滚动，并提供“全部 ▼”可搜索列表。
- 中间主体显示当前二级 Tag 的多选词条卡片。
- 右侧显示已选内容，可拖动排序。
- 不再区分选择模式和管理模式；一级、二级与词条在同一窗口维护。
- 一级 Tag 和词条卡片可通过右键或悬停 `···` 进入增删改；二级 Tag 顶部导航不再显示 `···`，直接右键导航项维护。
- 新增、改名、编辑和删除均使用自定义小窗，不使用浏览器原生提示框。
- 小窗点击“确定”后立即原子保存；“应用到节点”只提交当前节点选择。

## 4. 主要按钮

| 按钮 | 所在位置 | 行为 |
|------|----------|------|
| 词库文件 | 标题栏 | 切换、创建和装载词库文件；有未保存修改时先提示 |
| 搜索 | 标题栏 | 按中文、英文和来源路径过滤词条 |
| 文件管理 | 标题栏 | 新建、导入、改名、导出和删除词库 |
| 另存备份 | 节点与标题栏 | 打开系统保存位置选择，将全部 Bank YAML 打包为 ZIP |
| 新建一级分类 | 分类栏 | 创建一级分类并立即保存 |
| 新建二级分类 | 分类栏 | 在当前一级分类下创建二级分类 |
| 新建词条 | 词条栏 | 在当前二级分类创建词条 |
| 清空已选 | 已选栏 | 清空当前节点的临时选择，支持撤销 |
| 移除 | 已选词条 | 从当前节点选择中移除，不删除词库原词条 |
| 取消 | 底部 | 放弃本次节点选择变化并关闭 |
| 应用到节点 | 底部 | 保存当前选择、顺序、逐条权重和文本快照到节点 properties |

## 5. 词条字段

| 字段 | 用途 |
|------|------|
| 中文名称 | 浏览和中文搜索 |
| Prompt 文本 | 实际输出内容，可为英文或任意 Prompt |
| 词条权重 | 仅保存在当前 workflow 选择中；默认 `1` 原样输出，其他值输出为 `(Prompt:权重)` |
| 别名 | 扩展搜索，不参与输出 |
| 来源路径 | 搜索结果中显示所属文件和分类 |

## 6. 状态与边界

| 状态 | 展示 |
|------|------|
| 无词库文件 | 空状态 +“导入词库”与“新建词库” |
| 当前分类无词条 | 空状态 +“新建词条” |
| 搜索无结果 | 显示搜索词、清除搜索和搜索范围提示 |
| 词条来源失效 | 继续使用 workflow 中保存的中英文快照 |
| 保存冲突 | 提示文件已被外部修改，允许重新载入或另存 |
| 保存失败 | 不关闭弹窗，不清除草稿，显示原因和重试按钮 |
