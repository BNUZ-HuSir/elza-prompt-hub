# Elza Random Prompt · 产品功能规格

> 所属分类：Elza / prompt  
> 状态：0.2.0-alpha.4 待 UI 验收  
> 最后更新：2026-09-02

## 1. 功能定位

提供一个尽量精简的随机 Prompt 节点：用户只编辑一个多行 Prompt，节点下方实时显示每个随机选项的出现概率，执行时输出一次随机展开结果。

## 2. 节点界面

| 界面项 | 类型 | 行为 |
|------|------|------|
| prompt | 可编辑多行 STRING | 输入普通文本或公共随机语法 |
| probability_display | 只读多行说明 | 输入变化后约 120ms 更新概率 |
| text | STRING 输出 | 输出随机展开后的 Prompt |

节点只有一个可编辑多行框；概率区域是只读结果，不作为第二个 Prompt 输入。

## 3. 概率显示

| 语法 | 显示示例 |
|------|----------|
| `{a|b|c}` | a、b、c 各 33.33% |
| `{0.5::a|1.5::b}` | a 为 25%，b 为 75% |
| `{2$$a|b|c}` | 每个选项的出现概率为 66.67% |
| `{a|}` | a 为 50%，空选项为 50% |

- 多个随机块分别显示。
- 无随机语法时提示文本会 100% 原样输出。
- 非法语法直接显示错误原因。
- 多选使用无放回抽取的实际出现概率；极端大组合会明确标记为近似值。

## 4. 执行规则

- 每次 Queue 都重新随机展开，避免被 ComfyUI 缓存固定。
- 概率显示和执行共用 `prompt_syntax.py`，不在前端复制另一套概率算法。
- 支持的语法范围与 Prompt Switch 完全一致。
