# Elza Prompt Mixer · 产品功能规格

> 所属分类：Elza / prompt  
> 状态：0.2.0-alpha.12 待人工 UI 验收  
> 最后更新：2026-09-03

## 1. 功能定位

把结构化词库按“一级 Tag → 二级 Tag → 词条”显示在蓝图节点中。每个二级 Tag 单选一个中文词条或选择“不使用”，最终按照词库顺序拼接对应的英文 Prompt。

```text
Mixer YAML ─→ 蓝图节点加载全部一级/二级 Tag
                       ↓
             每个二级 Tag 单选一个词条
                       ↓
             workflow 保存中英文快照
                       ↓
              拼接并应用最终权重 ─→ text
```

Mixer 不提供随机、seed、固定/随机模式、随机概率、prefix 或 suffix。随机 Prompt 由 Elza Random Prompt 单独负责。

## 2. 节点本体

```text
┌ Elza Prompt Mixer ─────────────────┐
│ 最终权重                 [1.00]    │
│ [全部展开] [全部收起] [刷新] [管理] │
│                                   │
│ ▼ 人物                            │
│   发型        [黑色长发         ▼] │
│   表情        [温柔微笑         ▼] │
│ ▶ 摄影                            │
│                                   │
│ text                         ●    │
└───────────────────────────────────┘
```

| 控件 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 最终权重 | FLOAT | 1.0 | 1 时原样输出；其他值包装完整 Prompt |
| 全部展开 | 按钮 | — | 展开全部一级 Tag |
| 全部收起 | 按钮 | — | 收起全部一级 Tag，保留选择和输出 |
| 刷新词库 | 按钮 | — | 重新读取当前 Mixer YAML，不主动改写已保存选择 |
| 管理词库 | 按钮 | — | 打开一级、二级 Tag 和词条管理弹窗 |
| 一级 Tag 标题 | 折叠按钮 | 新节点首次载入全部收起 | 根据一级 Tag 数量计算节点初始高度；用户展开或收起后状态保存到 workflow，重新打开时恢复 |
| 二级 Tag 词条 | 可搜索下拉 | 不使用 | 显示中文名称，单选一个词条 |
| 清除 | `×` 按钮 | — | 清除当前节点保存值，不删除 YAML 数据 |
| text | STRING 输出 | — | 所有已选英文词组的拼接结果 |

## 3. 数据结构

Mixer YAML 只保存可读业务内容，不写文件、一级 Tag、二级 Tag 或词条 ID。文件定位由 YAML 文件名承担：

```text
词库文件
└─ 一级 Tag：人物
   ├─ 二级 Tag：发型
   │  ├─ 中文名称：黑色长发
   │  └─ 英文 Prompt：long black hair
   └─ 二级 Tag：光线
      ├─ 中文名称：电影感侧光
      └─ 英文 Prompt：cinematic side lighting, rim light
```

英文 Prompt 可以是一项词，也可以是逗号分隔的一整组词。

## 4. Workflow 快照

选择词条时，将以下数据复制到当前节点：

- 一级 Tag 中文名称。
- 二级 Tag 中文名称。
- 词条中文名称快照。
- 英文 Prompt 快照。
- 一级 Tag 折叠状态。
- 最终权重由原生 FLOAT widget 保存。

执行时只读取 workflow 中的英文快照，不需要根据 ID 回查 YAML。

## 5. 加载与缺失处理

| 情况 | 节点行为 |
|------|----------|
| YAML 正常且中英文完全匹配 | 显示当前词库选项并恢复普通选中状态 |
| YAML 中找不到已保存词条 | 显示“中文名（工作流保存）”，继续输出英文快照 |
| 一级或二级 Tag 被删除/改名 | 以工作流保存分组保留已有选择，允许清除或改选 |
| YAML 无法读取 | 显示加载失败提示，workflow 已保存内容仍可输出 |
| 新节点且 YAML 无法读取 | 没有可选项，输出空字符串 |

历史保存值可通过行末 `×` 或下拉框中的“不使用”清除；清除只影响当前节点。

## 6. 拼接与最终权重

拼接顺序固定为 YAML 的一级 Tag 顺序、二级 Tag 顺序，分隔符为 `, `。折叠状态和用户点击顺序不影响输出顺序。

| 已选内容 | 最终权重 | 输出 |
|----------|----------|------|
| `A` | 1 | `A` |
| `A` | 1.1 | `((A):1.1)` |
| `A, B` | 1 | `A, B` |
| `A, B` | 1.1 | `((A, B):1.1)` |
| 空 | 任意 | 空字符串 |

## 7. 管理弹窗

- 左侧显示一级分组。
- 中间显示二级“混合项”容器卡片，卡片展示名称、候选数量与前三项中文预览。
- 点击混合项卡片打开候选词组管理小窗。
- 候选小窗内维护中文名称和英文 Prompt，并支持新增、编辑与删除。
- `···` 与右键菜单用于改名、删除一级分组和二级混合项。
- 每次 CRUD 在自定义小窗确认后立即原子保存，并热刷新画布中的相关 Mixer 节点。
- 文件管理支持新建、导入、改名、导出、另存全部备份和删除。
- 管理弹窗标题栏提供“打开文件夹”，直接打开当前 YAML 所在的数据目录。
- 同一个二级 Tag 内出现重复中文名称时阻止保存并提示。
- 管理操作写入 YAML；节点下拉选择只写入 workflow。删除后的选择继续以橙色工作流保存值输出。
