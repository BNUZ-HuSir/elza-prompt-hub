# Elza Prompt Hub 全局开发约定

> 最后更新：2026-09-10

## 1. 节点与弹窗职责

### 1.1 节点本体

- 只放执行时常用的参数、简短摘要和打开编辑器按钮。
- 复杂列表、分类树、批量编辑和文件管理统一放入弹窗。
- 禁止通过重建节点更新 UI。
- 禁止删除或重排已有 widget。
- 已连接 STRING 输入优先于本地 widget，包括连接值为空字符串的情况。

### 1.2 弹窗

- 默认采用 ComfyUI 兼容的深色界面。
- 标题栏、搜索、状态提示、关闭按钮和底部操作栏由公共弹窗框架提供。
- 主操作只有一个高强调按钮；危险操作必须单独确认。
- 词库 CRUD 点击小窗“确定”后立即原子保存；节点选择仍通过“应用到节点”单独提交。

## 2. 用户数据

### 2.1 存储原则

- Prompt Bank 主数据保存在插件相对目录 `wordbanks/promptbank/`。
- Prompt Mixer 主数据保存在插件相对目录 `wordbanks/promptmixer/`。
- “另存备份”只生成内存 ZIP，并由系统保存位置选择器写入用户指定位置，不在词库目录中创建备份文件。
- 覆盖更新插件时必须保留 `wordbanks` 目录；发布包只携带空目录占位，不覆盖用户 YAML。
- 首次使用新版路径时检测旧 ComfyUI 用户数据目录并复制 YAML，旧文件不删除。
- 首次启动检测插件目录中的旧 `wordbank*.yaml`，分别迁移为独立词库，但不删除或修改旧数据。
- 文件保存采用临时文件写入后替换，保存失败时保留原文件。

### 2.2 节点选择快照

- Bank 与 Mixer 不为分类、分组和词条建立稳定 ID 索引。
- YAML 文件名作为文件定位 key，文件内容本身不写任何 ID 字段。
- 用户选中词条后，把中文名称、英文内容和来源路径复制到 workflow。
- YAML 只负责提供候选数据，不作为节点执行时的依赖。
- 当前 YAML 无法匹配时继续使用快照，并显示“工作流保存”状态。
- 用户可以清除历史保存值；清除只影响当前节点，不修改 YAML。

## 3. 状态与反馈

| 状态 | UI 表现 |
|------|---------|
| 已保存 | 显示对勾和“已保存” |
| 保存中 | 当前操作暂时禁用并显示“保存中…” |
| 保存失败 | 恢复操作前的数据并显示失败原因 |
| 外部文件变化 | 提示重新载入或另存，不静默覆盖 |
| YAML 无法匹配 | 保留快照输出，并显示“工作流保存”提示 |

## 4. Prompt 处理

- 公共解析器支持 `{a|b|c}`、`{0.5::a|1.5::b}`、`{2$$a|b|c}` 和 `{a|}`。
- Bank 与 Mixer 不提供单词条权重。
- Mixer 不提供随机概率；随机语法由支持该语法的其他 Prompt 节点负责。
- Bank 与 Mixer 的“最终权重”作用于完整拼接结果；值为 1 时不增加括号。
- 拼接前去除空片段，保留用户片段内部文本，不擅自改写内容。
- 分隔符由节点定义，默认使用 `, `。

## 5. UI 通用规则

- 使用 4/8px 间距体系，主要控件高度不低于 36px。
- 不使用 emoji 作为结构图标，统一使用线性 SVG 图标。
- 键盘可访问：Tab 顺序与视觉顺序一致，Esc 关闭前检查未保存状态。
- 搜索无结果时显示原因和清除搜索操作，不展示空白区域。
- 不只依赖颜色表达状态，同时提供图标和文字。
