Prompt Bank

按钮功能
词库文件切换当前词库；“合并视图”只读并显示准确来源。
管理词库进入文件、分类、词条的草稿编辑模式。
新建分类/词条只修改管理草稿，保存前不写文件。
清空清除当前节点已选内容，不删除公共词条。
应用到节点保存当前节点的选择、顺序、权重和文本快照。

换一个仅改变预览 seed；应用后才写入节点。
